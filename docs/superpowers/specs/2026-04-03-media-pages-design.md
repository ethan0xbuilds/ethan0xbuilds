# 书影记录页设计文档

**日期：** 2026-04-03  
**项目：** ethan0xbuilds 个人网站 (oasaka.xyz)

---

## 概述

为个人网站新增两个独立静态页面，用于记录已读书籍和已看电影。页面风格与主页 `index.html` 保持一致（深靛蓝渐变背景 + 玻璃拟态卡片），数据以硬编码 HTML 方式维护。

---

## 页面结构

新增两个文件：

- `books.html` — 书单页
- `movies.html` — 影单页

三个页面之间的导航关系：

```
index.html  ←→  books.html  ←→  movies.html
```

### 每个页面的布局（从上到下）

1. **返回主页按钮** — 左上角或居中，半透明胶囊样式，链接到 `index.html`
2. **页面标题** — 书单页显示"📚 书单"，影单页显示"🎬 影单"
3. **副标题** — 英文小字，书单为 "Reading List"，影单为 "Watching List"
4. **跨页导航** — 两个胶囊按钮，当前页高亮，另一个链接到对应页面
5. **卡片网格** — 2-3 列响应式网格，每格一条记录
6. **页脚** — 与主页一致的版权信息

---

## 卡片设计

每张卡片包含以下字段：

| 字段 | 说明 |
|------|------|
| 封面图 | `<img>` 标签；无图时用 emoji 占位（书用 📖，电影用 🎬） |
| 标题 | 书名或电影名 |
| 评分 | 1-5 星，用 ★/☆ 表示 |
| 完成日期 | 格式 `YYYY-MM-DD` |
| 感想 | 一句话简评，最多两行（CSS 截断） |

卡片样式：玻璃拟态，`background: rgba(255,255,255,0.1)`，`backdrop-filter: blur`，圆角 12px，封面图占据卡片上半部分（宽高比 2:3）。

## 数据维护方式

纯手动编辑 HTML。添加新记录时，在对应页面的网格容器里复制一个卡片 `<div>` 并填写内容即可。最新记录放在最前面（倒序）。

---

## 样式规范

复用主页已有 CSS 变量和类：

- 背景：`linear-gradient(135deg, #1a1a2e 0%, #16213e 50%, #0f3460 100%)`
- 装饰光晕：`.orb` 类，同主页三个光球
- 玻璃卡片基础样式：`rgba(255,255,255,0.15)` + `backdrop-filter: blur(20px)`
- 字体：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`

响应式：移动端（`max-width: 480px`）降为单列网格。
